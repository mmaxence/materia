ORDERED COMPOSITION

Build a layer stack.

Apply up to six optics, geometry, or signal effects in order. Each layer processes the result before it. Adjust a layer without rebuilding; remount a reordered stack when changing its structure.

Try the layer editor ↗ 
import { stack } from '@materia/text/stack';
import { vortex } from '@materia/text/geometry/vortex';
import { pixelate } from '@materia/text/signal/pixelate';
import { rgbSplit } from '@materia/text/signal/rgbSplit';

const fx = createTextEffect(heading, {
  effect: stack([
    { effect: vortex, strength: 0.7, scale: 12 },
    { effect: pixelate, strength: 0.6, scale: 8 },
    { effect: rgbSplit, strength: 0.5, scale: 14 },
  ]),
  auto: true,
});
fx.setLayer(1, { strength: 0.8 });

One canvas. Two reusable textures. Zero runtime dependencies. Water, smoke, glyphs, and physics stay standalone.

03 / THE ESSENTIALS

A small, explicit API.

createTextEffect(element, options)

Configure the effect

effect
Required. An imported effect definition.
strength / scale
Intensity from 0–1; detail scale from 1–24.
signal
Optional treatment layered on a GPU effect. Canvas families run independently.
signalStrength / signalScale
Adjust the signal separately from the base effect.
auto / frozen
Enable autonomous motion or hold a frame.
host / color
Canvas bounds default to the parent. GPU color accepts RGB values from 0–1.
consumed / waterline
Elemental consumption; waterfall pool height from 0.4–0.9.

Control its lifecycle

pulse()
Trigger a disturbance.
setStrength(value) / setScale(value)
Tune the effect without remounting.
setAuto(bool) / setFrozen(bool)
Control motion and pause state.
setSignal(strength, scale?)
Adjust an attached signal.
setLayer(index, changes)
Update strength, scale, or enabled state in a stack.
setConsumed(bool)
Switch elemental consumption.
refresh() / supported
Refresh geometry; inspect renderer availability.
destroy()
Release resources and restore original styles. Safe to call again.

Browser mounted. Imports are SSR-safe. Create effects on connected, plain-text elements in the browser.

Native fallback. Source text stays accessible. Reduced motion and unavailable renderers fall back gracefully.
